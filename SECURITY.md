# Security Policy

## Reporting Security Concerns

Do not report security concerns using public GitHub issues if the report contains sensitive information.

Do **not** upload or include:

- Real case evidence
- Private captures
- Victim information
- Suspect information
- Credentials
- Cookies
- Tokens
- API keys
- Subscriber information
- Investigative notes
- Law enforcement sensitive material

## Preferred Reporting Method

For now, security concerns should be reported directly to the project maintainer.

If a concern can be described without sensitive information, you may open a GitHub issue using sanitized details only.

## Scope

This project is a local-first Chrome extension for OSINT web capture and evidence-package documentation.

Security concerns may include:

- Accidental collection of sensitive data
- Unintended exposure of investigator/device/network information
- Unsafe handling of exported capture packages
- Problems with hashing or integrity documentation
- Extension permission concerns
- Bugs that could alter, lose, or misrepresent captured data

## Important Notice

CaseCapture OSINT Agency Edition is not a certified forensic tool.

Agencies and users should validate the tool in their own environment before operational use.

Do not rely on this tool as the sole method of preserving online evidence when legal process, platform preservation, subpoenas, warrants, screenshots, reports, or other investigative methods are appropriate.
