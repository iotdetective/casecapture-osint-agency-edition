# CaseCapture OSINT Agency Edition

CaseCapture OSINT Agency Edition is a local-first Google Chrome extension designed to help investigators document web content observed during OSINT and online investigations.

The extension captures browser-observed content, screenshots, page metadata, visible text, extracted links, image references, limited network observations, method logs, SHA-256 hashes, and a reviewable evidence package. The exported package includes an `index.html` landing page, human-readable reports, supporting artifacts, documentation, and integrity information.

The tool is designed for controlled investigative environments such as Windows Sandbox, clean virtual machines, ephemeral desktops, dedicated OSINT browser profiles, or agency-managed forensic workstations.

CaseCapture OSINT does not independently authenticate online content, identify account owners, prove authorship, or replace legal process, preservation requests, subpoenas, warrants, platform records, or agency validation. It documents what was observed in the investigator’s Chrome browser session at the time of capture.
